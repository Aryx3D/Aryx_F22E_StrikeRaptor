# Aryx's F-22E Strike Raptor
Proposed in the late 2040s as an upgrade and overhaul package for the F-22C in the midst of the Third World War, the F-22E Strike Raptor takes the familiar F-22 aeroform and introduces a pair of midfuselage-chine EOTS for guiding precision-guided munitions, as well as a deepened and expanded weapon bay for carriage of large volumes of ordinance. Excellent agility, thrust vectoring, able to equip stealth weapon pods on its inner wing pylons, and now well-capable of ground attack as well as air dominance, the F-22E is just as fierce as its original design was half a century prior.

REQUIRES BLUEPRINTER!

Installation Guide / / / /
1) You will need to install Bepinex into nuclear option first. Bepinex is a modloader.
https://docs.google.com/document/d/16aRWcrkt89YEn9_THwe9Fxo7AYPLE9SYSab_Y929dvE

2) Install Nikkorap's Blueprinter mod, which allows loading of arbitrary nuclear option assetbundles.
https://github.com/nikkorap/NOBlueprinter-Releases/releases/latest

3) Download the .dll file from this repository's Releases and place it into Nuclear Option/Bepinex/Plugins.
